# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の素のLLMには講座固有の情報を検索する機能がなかった。第3回のエージェントでは、用語集を参照し、宿題の3レベルについて「基礎・実装・発展のうち1つを選べばよい」と回答した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：search_glossary({'query': 'LoRA'}) と search_glossary({'query': 'QLoRA'}) が呼び出された。また、追加した make_quiz が第2回の用語から「過学習」の確認問題を作成した。
- 1つの質問での LLM 呼び出し回数（`requests`）： LoRAとQLoRAの違いを質問した際は requests=2、tool_calls=2 だった。確認問題を作成した際は requests=2、tool_calls=1 だった。
- 追加したツールと、docstring に書いた説明：make_quiz(lecture: int) -> str を追加した。指定した回の用語から1つを選び、確認問題と答えを返す。docstringには「復習用の問題を求められたときに使う」と記載した。ツール登録後、15個の自動テストがすべて成功した。

## 宿題

- 取り組んだレベル：基礎 
- やったこと：app/agent.py の INSTRUCTIONS に記載されていた「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する」という指示を削除した。
- 結果：変更前と変更後で、同じ質問「LoRA と QLoRA の違いは？」を --trace オプション付きで実行し、比較した。

変更前：search_glossary がLoRAとQLoRAについてそれぞれ呼び出された。requests=2、tool_calls=2。

変更後：同様にLoRAとQLoRAについてそれぞれ検索が行われた。requests=2、tool_calls=2。

回答内容にも大きな違いは見られなかった。
- 気づき・疑問：「必ず検索する」という指示を削除しても、検索の実行回数や回答内容に大きな変化は見られなかった。

これは、search_glossary のdocstringにも「答える前に使うこと」と記載されているため、その説明文がモデルのツール選択に影響した可能性がある。

今回の実験から、AIエージェントの動作は、全体への指示文だけでなく、個々のツールの説明文によっても左右される可能性があることを理解した。
